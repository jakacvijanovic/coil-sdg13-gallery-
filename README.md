# COIL 2026 — SDG 12
Interactive student gallery about responsible consumption and electronic waste.

## Objava na GitHub Pages
1. Ustvari javni repozitorij `coil-sdg12-gallery`.
2. Razširi ZIP in naloži VSE datoteke in mape iz notranje mape projekta v koren repozitorija (index.html mora biti v korenu).
3. Settings → Pages → Deploy from a branch → main → /(root) → Save.
4. Odpri povezavo, prikazano v Settings → Pages.

## Prilagoditev
- V `index.html` zamenjaj imeni dijakov, besedilo in opise prispevkov.
- Vsak dijak doda šest lastnih fotografij: `assets/images/dijakA/photo1.jpg` do `photo6.jpg`, enako za `dijakB`. Če uporabiš drugačna imena ali končnice, popravi `gallery-data.js`. Tam spremeni tudi naslove, kategorije in opise (po želji razširi posamezne vnose).
- V `index.html` zamenjaj video placeholder z npr. `<iframe src="https://www.youtube-nocookie.com/embed/VIDEO_ID" title="Introduction video" allowfullscreen></iframe>` ali `<video controls src="assets/videos/studentA.mp4"></video>`. Uporabi dejanski ID videa oziroma datoteko. Pri javni objavi osebnih fotografij in videov poskrbi za soglasje.
- Anketa je demonstracija, glasovi se hranijo samo v istem brskalniku, niso skupni vsem obiskovalcem.
- Za lokalni predogled odpri index.html v brskalniku.
